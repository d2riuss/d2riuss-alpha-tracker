# =====================
# OPCIÓN A: RAILWAY (Recomendada - Gratis)
# =====================

# PASO 1: Crear cuenta en Railway
# Ve a https://railway.app y regístrate con GitHub o email

# PASO 2: Crear un nuevo proyecto
# 1. Click en "New Project"
# 2. Selecciona "Empty Project"
# 3. Click en "Add Service" → "Empty Service"

# PASO 3: Conectar tu código
# 1. En tu servicio, ve a "Settings"
# 2. En "Source", selecciona "Upload"
# 3. Sube los archivos:
#    - darius_alpha_tracker.py
#    - requirements.txt

# PASO 4: Configurar el comando de inicio
# 1. En "Settings" → "Deploy"
# 2. En "Start Command" escribe:
#    python darius_alpha_tracker.py setup
# 3. Espera a que se ejecute el setup
# 4. Luego cambia el comando a:
#    python darius_alpha_tracker.py

# PASO 5: ¡Listo!
# El bot estará corriendo 24/7 y recibirás alertas en Telegram

# =====================
# OPCIÓN B: RENDER (Alternativa gratuita)

# PASO 1: Ve a https://render.com y regístrate

# PASO 3: Sube tu código o conecta un repo de GitHub
# PASO 4: Build Command: pip install -r requirements.txt
# PASO 5: Start Command: python darius_alpha_tracker.py
